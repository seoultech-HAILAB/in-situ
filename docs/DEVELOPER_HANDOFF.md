# 개발 인계 — 2026-11-02

## 전달 범위

이 커밋은 현재 구현된 UI·백엔드·검증 코드와 PILOT4 연습 1개/후보 10개를 전달한다. API 키, 개인 계정, 참가자 기록과 원본 실험 덤프는 전달하지 않는다. 코드·자연어 설명을 테이블 내부에 연결하는 최근 설계 논의는 미구현이다. 현재 In-situ는 코드 비공개다.

## 깨끗한 PC에서

1. Python 3.13, Node.js 22 이상, Git 설치 후 저장소 clone.
2. `.env.example`을 `.env`로 복사하고 자신이 사용할 API 키·모델 설정. 키를 커밋하지 않는다.
3. Windows에서 `start.cmd` 실행 후 http://127.0.0.1:8000/ 접속. 로그인 없음.
4. 과제 선택 후 Input·Target을 확인하고 시작. 저장 코드의 실제 중간 결과를 관찰한다. `?research=1`에서 과제 자료와 개발자 옵션 확인.
5. 자연어 수정 후 전체 재실행, 후속 표 갱신, 되돌리기와 최종 확정 확인.

모델 키 없이 저장 코드를 실행할 수 있으나 설명 캐시가 없으면 설명은 준비되지 않는다. 자유로운 자연어 수정은 API가 필요하며 자동 mock 대체는 없다.

## 과제 자료

`tasks/manifest.json`은 포함 JSON의 SHA-256을 기록한다. JSON은 Input/Target/추가 표, 초기 코드·Step, 참조 코드·검증 메타데이터를 포함한다. 원본 파일 경로가 출처에 남아 있어도 런타임에서 그 경로를 읽지 않는다. 초기 모델 호출은 없다. 연구자 평가 자료는 참가자 응답과 분리한다.

첫 접근 시 배포 스냅샷을 `.local/pilot/candidates`로 한 번 복사한다. 초기화된 폴더는 재시작해도 덮어쓰지 않는다. 별도의 과제 집합은 `TRACE_TASK_DIR`로 지정할 수 있다. 현재 로컬 작업용 폴더가 있는 개발자는 포함 JSON과 자신의 로컬 과제 집합이 다를 수 있다는 점을 확인한다.

## 실행/수정 위치

- `src/ReviewWorkspace.tsx`, `src/main.tsx`: 두 조건의 검수 화면·표·선택·수정 연결.
- `src/TableViewport.tsx`: 모든 표의 head/펼치기/내부 스크롤.
- `backend/app.py`: 공통 세션·수정·재실행·투영 API.
- `backend/python_runtime.py`, `backend/python_provenance.py`: 실제 실행 관찰과 선택적 상세 추적.
- `backend/generation.py`, `backend/explanations.py`: 모델 기반 코드 수정 및 관찰 코드 설명.
- `backend/candidates.py`: 배포 과제의 로컬 초기화·조회·등록.

설명은 현재 코드 동작에 기반해야 하며 목표에 맞춘 이상적 과정이나 오류 위치 힌트를 만들지 않는다. 상세 계보가 없는 연산에도 실행 IO는 제공한다. 정해진 Task에 대한 정답 변환 규칙으로 일반 수정을 대체하지 않는다.

## 접속과 기록

기본 실행과 `scripts/start-team.ps1` 모두 로그인/비밀번호 없이 동작한다. 과거 로그인 파일은 기본 실행에서 무시한다. 현재는 개인별 계정 배정/격리를 사용하지 않으므로 랩실 개발 점검용이다. 원본 기록은 지우지 않았으며 Git에서 제외된다. 공개 실험 운영용 인증·권한 정책은 별도 과제다.

`share-team.ps1`은 필요할 때만 수동 실행한다. URL 접속자는 개발자 기능과 서버 API 사용이 가능하므로 신뢰하는 개발자에게만 전달한다. 이 인계 작업에서는 새 외부 URL을 만들지 않는다.

## 검증

`python -m pytest -q`, `npm.cmd run build` 실행. 최초 실행 과제 복사·기존 과제 미변경·옛 인증 파일 무시를 회귀 검증한다. 전체 과제의 자연어 수정 성공률이나 최근 In-situ 제안의 효과를 검증했다는 뜻은 아니다.

### 이번 인계 검증 결과

- 전체 Python 테스트 171개 통과. 폐기된 ABC/B2 조건 기대값은 현재 두 조건 및 과거 입력 정규화 기준으로 갱신했다.
- UI/선택/추적 테스트 34개 통과, 프로덕션 빌드 성공. 과거 실험 출력이 필요한 선택적 이력 테스트 2개는 깨끗한 clone에서 생략된다.
- 배포 JSON 11개만 사용해 native 격리 실행과 Step 조립을 모두 확인했다. 원본 Downloads 폴더·모델 호출·참가자 로그를 사용하지 않았다.
- 현재 API 키·계정 설정과 대조해 공유 파일의 자격정보 포함 여부를 검사했다. `.env`/`.local`/원본 실험 출력은 제외했다.
- 브라우저 검사나 새로운 실제 LLM 호출은 수행하지 않았다.

현재 서버가 제공하는 `dist/index.html` 및 JS/CSS 번들도 저장소에 포함한다. 2026-11-02 현재 서버 응답과 파일 해시를 대조해 동일함을 확인했다. 소스 변경 시 빌드를 갱신해야 한다.
